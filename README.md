# FS25-Mod-Mix

Privat. Alle Mods, die der Silverrun-Spielstand (savegame2) verwendet, im aktuellen Stand.

**Herunterladen:** Releases → neuestes Release → jede ZIP einzeln anklicken. Die ZIPs unverändert in den `mods`-Ordner legen, nicht entpacken.

Dateien über 100 MB (Karte, Volvo Pack) liegen im Repo in Teilen unter `parts/`. Das Release setzt sie automatisch wieder zu einer ZIP zusammen und prüft alle Dateien gegen `checksums.md5`.

Neues Release: `RELEASE_TAG` ändern und pushen, oder unter Actions → Release → „Run workflow“.
