# FS25-Mod-Mix

Privat. Die Mods des Silverrun-Spielstands (savegame2), die es nicht im ModHub gibt: eigene Mods, bearbeitete Mods und Umbauten. ModHub-Mods lädt man im Spiel herunter.

| Mod | Herkunft |
|---|---|
| FS25_silverrunForestCustom | Silverrun Forest, eigene bearbeitete Version |
| FS25_Silverrun_Forest_Improved | eigener Mod (Sägewerk-Addon) |
| FS25_ForestryPhysicsExperimental | eigener Mod |
| FS25_WoodHarvesterControls | Bargon Mods (GitHub), mit eigenen Fixes |
| FS25_JD_1210G_Improved | ModHub-Mod von Rimvis, eigene Bearbeitung |
| FS25_LumberShed | Umbau eines FS22-Mods |
| FS25_woodstack | Umbau eines LS19-Mods |

**Herunterladen:** Releases → neuestes Release → jede ZIP einzeln anklicken und unverändert in den `mods`-Ordner legen.

Die Karte ist größer als 100 MB und liegt deshalb in Teilen unter `parts/`. Das Release setzt sie automatisch zusammen und prüft alle Dateien gegen `checksums.md5`.

Neues Release: `RELEASE_TAG` ändern und pushen, oder unter Actions → Release → „Run workflow“.
